01 · Easing

同样的距离，不同的“性格”

缓动决定动画如何加速和减速。真实界面通常不是匀速移动：按钮反馈适合快速收尾， 弹层适合带一点回弹，强调动画则可以使用弹跳或弹性效果。

Ease comparison
none
power2.out
power4.inOut
back.out(1.7)
bounce.out
elastic.out
实现要点：用函数动态计算每条轨道的可移动距离，窗口尺寸变化后依然不会越界。
gsap.to()easefunction value
function playEasing() {
  document.querySelectorAll(".ease-ball").forEach((ball) => {
    gsap.fromTo(
      ball,
      { x: 0 },
      {
        x: () => ball.parentElement.clientWidth - ball.offsetWidth - 20,
        duration: 2.2,
        ease: ball.dataset.ease
      }
    );
  });
}

  duration: 0.45,
  ease: "power3.out"

const rotateY = gsap.quickTo(card, "rotationY", {
  duration: 0.45,
  ease: "power3.out"
});

card.addEventListener("pointermove", (event) => {
  const rect = card.getBoundingClientRect();
  const x = (event.clientX - rect.left) / rect.width - 0.5;
  const y = (event.clientY - rect.top) / rect.height - 0.5;
  rotateY(x * 14);
  rotateX(y * -14);
});

08 · Motion Path

沿 SVG 路径移动并自动旋转

这里不用 MotionPathPlugin，而是通过 getPointAtLength() 按进度读取路径坐标， 再用前后两个点计算切线角度。适用于地图航线、流程节点和设备轨迹。

Follow the curve.

将一个普通对象的 progress 从 0 补间到 1；每次更新时读取 SVG 路径的位置， 并把 SVG 坐标换算为当前地图容器中的像素坐标。

Distance2,104 km
Progress0%
实现要点：路径坐标与容器像素尺寸可能比例不同，需根据 viewBox 做缩放转换。
getPointAtLength()atan2()onUpdate
const state = { progress: 0 };
const total = path.getTotalLength();

gsap.to(state, {
  progress: 1,
  duration: 4,
  ease: "power1.inOut",
  onUpdate() {
    const point = path.getPointAtLength(total * state.progress);
    const next = path.getPointAtLength(
      Math.min(total, total * state.progress + 1)
    );
    const angle =
      Math.atan2(next.y - point.y, next.x - point.x) * 180 / Math.PI;

    gsap.set(plane, { x, y, rotation: angle });
  }
});
09 · ScrollTrigger

把滚动变成时间轴控制器

向下滚动时，卡片横向移动；动画进度和滚动位置绑定，并在桌面端固定当前场景。

CHAPTER 01

Start with hierarchy

先确定用户应该看到什么，再决定动画顺序。视觉层级比复杂特效更重要。

CHAPTER 02

Control the rhythm

合理重叠动画，避免所有元素同时启动。节奏应服务信息理解，而不是炫技。

CHAPTER 03

Respond to input

滚动、鼠标和触摸输入都可以驱动动画，但必须保持可控、可预测和可退出。

CHAPTER 04

Respect accessibility

检测 prefers-reduced-motion，为易眩晕用户提供更少位移、更短时长或无动画版本。
